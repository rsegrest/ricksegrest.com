# Jira Python book

At NASA, I built three automation tools that connected to Jira and Confluence, the project management software our teams use every day. These tools eliminated hours of manual reporting every week for over 50 engineers. Instead of copying data between spreadsheets and Jira by hand, a script did it in seconds. The tools worked so well that NASA awarded me a TIPI Grant (Technology Infusion Partnership Initiative) to write a 100-page book teaching other teams how to do the same thing.

The book starts from absolute zero. Here's how to install Python. Here's what a variable is. It builds up to real automation: querying project data, creating tickets automatically, generating reports, managing workflows. Every concept has a runnable code example in the companion GitHub repository.

I wrote it for non-programmers. Engineers, managers, and administrators who use Jira every day but have never written a line of code. The goal was to show them that a 20-line script could replace hours of manual work, and that they could write that script themselves. Not "learn to code" in the abstract. "Here's the specific thing you're doing by hand this afternoon, here's how to make the computer do it instead."

Most enterprise software training focuses on clicking through the UI. But the real productivity multiplier is automation, teaching people to make the computer do the repetitive parts. The book has been used across multiple NASA teams, and the companion code repository is public so anyone can learn from it.

The meta lesson I wasn't expecting: writing a book for beginners forces you to understand your subject at a much deeper level. You can't hide behind jargon. You can't skip steps. Every concept has to be explained from first principles, and if you can't explain it from first principles, you don't understand it as well as you thought you did. That discipline has made me a better engineer and a better teacher.

The repo is at rsegrest/jira-python-book. The code is public. If you spend your afternoons copying data from one screen to another, read it.
